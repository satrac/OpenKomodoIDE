# Support policy

**This fork is experimental. No user support is provided.**

The repository is a community continuation of Komodo IDE and is not
affiliated with, endorsed by, or supported by ActiveState.

- There is no guaranteed response time for issues.
- There is no support contract, mailing list, chat channel, or installation
  help.
- The software is provided as-is, under the repository's license, without
  warranty.
- Komodo Edit is out of scope.

## What is welcome

Pull requests are welcome, including build fixes, Python 3 ports, packaging
fixes, documentation, and compatibility work. Please include a short
description of what was tested and how.

See [CONTRIBUTING.md](CONTRIBUTING.md).
